Age-Points-Rate Validator

This is my first C++ practice project.

The program asks the user to enter:

* Age
* Points
* Rate

It checks if all three conditions are true:

* Age > 18
* Points > 500
* Rate > 5

If all conditions are met, the program prints a success message. Otherwise, it prints a message saying that the conditions are not satisfied.
